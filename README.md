# ECE520L_Blinking_LED
Lab 1 : Blinking RGB LED's on the Zybo Z7-10 Board. 

Goal: Blink the LED of the Zybo Z7-10 with a given set of IO ports and parameters in order to blink the LED's every 500 ms and be able to change the color using the onboard switches and use combinational logic to allow for a certain color or turn off the LED. The Zybo Z7-10 file was also implemented by copying the code from a GitHub Repo and uncommenting certain lines of code and then changing the names of the ports in order to meet the given parameters.
